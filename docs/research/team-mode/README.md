## 阅读建议

- **第一次用**：按 1 → 2 → 3 的顺序读。先会写蓝图，再会管成员，再理解 Leader 怎么干活。
- **要配严格权限**：读 1 的第 2.6 和 2.12 节，再读 4。
- **团队跑起来了要盯着**：读 5。
- **重启后找不到团队**：读 6 的第 3 节。
- **遇到报错**：每篇末尾都有常见问题表。
